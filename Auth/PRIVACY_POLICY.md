# FMA Viewer 개인정보 처리방침

시행일: 2026년 8월 4일 (이메일·비밀번호 로그인 반영)

FMA Viewer(이하 “앱”)는 브라우저에서 이미지와 영상을 관리·편집하는 도구입니다. 개발자 박중희는 앱의 최초 사용자 확인과 문의 대응을 위해 아래와 같이 최소한의 개인정보를 처리합니다.

## 1. 처리하는 개인정보

앱을 처음 사용할 때 다음 정보를 입력하거나 생성합니다.

- 사용자가 입력한 Gmail 주소
- 사용자가 입력한 이름과 소속
- 사용자가 작성한 사용목적
- 최초 사용 일자와 시각(시·분)
- 이메일 인증 일자와 시각
- 마지막 등록 확인 시각과 사용 상태(Active 또는 Blocked)
- FMA Viewer 전용 비밀번호의 솔트, 반복 횟수 및 단방향 인증 해시

일반 사용자 로그인에서는 FMA Viewer 전용 비밀번호 원문을 저장하거나 서버로 보내지 않습니다. 브라우저에서 PBKDF2-HMAC-SHA-256으로 파생한 인증값을 전송하고, 서버는 별도 보안 키로 다시 보호한 단방향 해시만 저장합니다. 관리자의 최초 공통 비밀번호는 첫 로그인 시 암호화된 HTTPS 연결로 GAS에 전달되어 확인되지만 저장되지 않으며, 강제로 변경한 관리자 비밀번호는 일반 사용자와 동일하게 브라우저에서 파생한 인증값만 전송·저장됩니다. Google 계정 비밀번호는 요구하거나 저장하지 않습니다.

## 2. 처리 목적

- FMA Viewer 최초 사용자 확인
- 최초 사용자 신청 기록
- 신청자 소속과 사용목적 확인
- 사용 현황 확인과 운영상 공지
- 등록 사용자의 로그인 인증과 세션 유지
- 문의, 오류 신고 및 지원 대응

입력한 Gmail 주소로 발송된 인증 링크를 열어 주소 소유와 전용 비밀번호 설정을 완료한 뒤 이메일과 비밀번호로 로그인하면 앱을 시작합니다.

## 3. 저장 및 전달 방식

- 인증을 기다리는 동안 Gmail, 이름, 소속, 사용목적, 동의·신청 시각 및 인증 요청 ID는 현재 브라우저의 로컬 저장소에 임시 보관됩니다. 비밀번호 원문과 비밀번호 인증값은 브라우저 저장소에 보관하지 않습니다.
- 사용자가 **아이디 저장**을 선택하면 Gmail 주소만 현재 브라우저의 로컬 저장소에 보관합니다. 로그인 세션 토큰은 해당 탭의 세션 저장소에만 보관되며 브라우저 탭을 닫거나 세션이 만료되면 다시 로그인해야 합니다.
- Google Apps Script는 입력한 Gmail 주소로 30분 동안 유효한 일회용 인증 링크를 발송합니다. 인증을 기다리는 동안 Gmail, 이름, 소속, 사용목적, 신청 시각, 인증 토큰 해시와 서버 보안 키로 보호된 비밀번호 인증 해시를 GAS Script Properties에 임시 보관하며 인증 토큰·비밀번호·브라우저 파생 인증값 원문은 저장하지 않습니다.
- 인증 링크가 열리기 전에는 신청 정보를 `Users` 탭에 기록하지 않습니다. 인증이 완료되면 Gmail, 이름, 소속, 사용목적, 신청·인증 시각, Active 상태, 비밀번호 솔트·반복 횟수·보호된 단방향 인증 해시가 Google Sheet의 `Users` 탭에 이메일당 한 행으로 저장됩니다.
- Google Apps Script는 인증 완료 후 `shoutjoy1@yonsei.ac.kr`로 신청자 Gmail, 이름, 소속, 사용목적과 신청·인증 시각이 포함된 알림 메일을 발송합니다.
- 앱은 로그인 성공 시 최대 8시간 유효한 임의 세션 토큰을 발급하고 서버에는 토큰 원문이 아닌 해시만 임시 저장합니다. 관리자 설정 주기에 따라 로그인 세션과 등록 상태를 확인하고, 실행 중에는 설정된 경량 감시 주기에 따라 `Blocked` 상태를 추가 확인합니다.
- 일시적인 서버 연결 실패 때는 기존 등록 사용자의 앱을 차단하지 않고 다음 실행 또는 재시도 시 다시 확인합니다.
- 인증 메일 발송, 신청 정보 저장과 알림 메일 처리에는 Google의 개인정보 처리방침과 보유 정책이 적용됩니다.
- 브라우저 데이터 또는 사이트 데이터를 삭제하면 저장된 아이디와 로그인 세션도 삭제될 수 있습니다.

앱은 사용자의 Gmail 계정으로 로그인하거나 사용자 계정에서 메일을 발송하지 않습니다. 인증 메일과 개발자 알림 메일은 Google Apps Script 실행 계정에서 발송합니다.

## 4. 이미지·영상 및 AI 기능

- 일반 보기, Crop, Canvas 편집, 로컬 배경 제거 등은 가능한 범위에서 현재 브라우저 안에서 처리됩니다.
- 사용자가 Google AI Studio 기반 AI 기능을 실행하면 선택한 이미지, 참고 이미지, 프롬프트 등이 Google Gemini API로 전송될 수 있습니다.
- 외부 내장 앱이나 링크를 열면 해당 서비스의 개인정보 처리방침과 이용약관이 적용됩니다.
- FMA 프로젝트, SaveDB 및 편집 결과는 사용자가 직접 저장하거나 삭제할 수 있습니다.

## 5. 보유 기간과 삭제

- 아이디 저장을 선택한 Gmail: 사용자가 아이디 저장을 해제하거나 브라우저 사이트 데이터를 삭제할 때까지
- 로그인 세션 토큰: 최대 8시간 또는 로그아웃할 때까지. 서버에는 토큰 해시만 저장됩니다.
- 미완료 인증 요청의 Gmail, 이름, 소속, 사용목적, 해시 토큰 및 보호된 비밀번호 인증 해시: 발송 후 30분 또는 새 인증 요청으로 교체될 때까지. 인증된 임시 요청은 최대 24시간까지 보관됩니다.
- Google Sheet의 이메일, 이름, 소속, 사용목적, 신청·인증 시각, 상태, 확인 기록 및 비밀번호 인증용 단방향 해시: 사용자 확인과 운영 목적이 끝날 때까지 또는 삭제 요청 처리 시까지
- 개발자에게 발송된 인증 완료 알림 메일의 신청자 정보: 사용자 확인 및 지원 목적이 끝날 때까지 또는 삭제 요청 처리 시까지

사용자는 개발자에게 이메일로 본인의 최초 사용자 알림 삭제를 요청할 수 있습니다.
