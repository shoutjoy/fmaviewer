기본 WebGL 엔진은 별도의 176MB ONNX 모델 다운로드 없이 사람 전경을 분리합니다.

기본값 · WebGL 로컬 처리
BG Remover 앱의 MediaPipe Selfie Segmentation 방식을 사용합니다. 최초 실행 시 경량 런타임을 불러오며 이미지는 외부 처리 서버로 전송되지 않습니다.
앱 폴더의 image_model/u2net_human_seg.onnx 파일을 우선 사용합니다. 파일이 없으면 원본 서버에서 약 176MB 모델을 내려받아 브라우저 저장소에 자동 연결합니다. 자동 연결이 실패한 경우에만 ONNX 파일을 수동 선택하세요. 이미지는 외부 처리 서버로 전송되지 않습니다.
