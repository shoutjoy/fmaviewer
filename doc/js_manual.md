# FMA Viewer JavaScript Manual

이 문서는 FMA Viewer Ultra의 모듈화된 JavaScript 구조와 주요 기능에 대한 기술 매뉴얼입니다. 모든 로직은 성능 최적화와 유지보수 편의를 위해 `js/` 폴더 내의 각 역할별 파일로 분리되어 있습니다.

---

## 📂 파일 구조 및 역할 (File Architecture)

### 1. `js/core/globals.js` - 전역 상태 및 DOM 캐시
애플리케이션 전체에서 공유되는 데이터와 DOM 요소 참조를 관리합니다.
- **이미지 데이터**: `images` 배열 (이미지 소스, 경로, 그룹, 즐겨찾기 상태 등 포함)
- **현재 상태**: `currentIndex` (현재 선택된 이미지 인덱스), `zoom` (확대 배율), `viewMode` (Single/Two), `orientation` (Horz/Vert) 등
- **DOM 캐시 (`dom` 객체)**: 빈번한 `document.getElementById` 호출을 방지하여 성능을 극대화합니다.

### 2. `js/storage/database.js` - 데이터 보관 (IndexedDB)
브라우저 종료 후에도 작업을 이어갈 수 있도록 데이터를 관리합니다.
- **자동 저장**: 이미지 추가, 삭제, 즐겨찾기 변경 시 즉시 IndexedDB에 반영됩니다.
- **세션 복구**: `initDB()`를 통해 마지막에 열었던 프로젝트 데이터를 자동으로 불러옵니다.

### 3. `js/gallery/gallery.js` - 좌측 리스트 및 갤러리 로직
갤러리 화면 구성과 썸네일 상호작용을 담당합니다.
- **성능 최적화**: `DocumentFragment`를 활용하여 수백 개의 이미지를 한 번에 렌더링하며, `loading="lazy"`를 적용하여 하드웨어 부담을 줄였습니다.
- **정렬 기능**: 최신순, 오래된순, 파일 크기순, 이미지 종류별, 그룹별 정렬을 제공합니다.
- **즐겨찾기 화면**: 별도의 사이드바 영역에 즐겨찾기된 이미지만 모아서 보여줍니다.
- **복구 시스템**: `deletedImages` 스택을 통해 실수로 삭제한 이미지를 역순으로 복구하는 기능을 포함합니다.

### 4. `js/gallery/preview.js` - 미리보기 및 메타데이터 렌더링
우측 큰 화면 표시와 관련 상세 로직입니다.
- **하단 메타데이터 바**: 현재 보고 있는 이미지의 경로를 표시하며, **각 이미지별 전용 `★ Favorite` 및 `Download` 버튼**을 동적으로 생성합니다.
- **듀얼 뷰(Two) 대응**: 2페이지 모드 시 하단 바가 좌우로 나뉘어 각각의 이미지 정보를 독립적으로 표시합니다.
- **방향 전환**: 가로 슬라이딩(Horz)과 세로 스크롤(Vert) 모드 간의 렌더링 전환을 처리합니다.

### 5. `js/files/fileHandlers.js` - 파일 처리 및 내보내기
외부와의 데이터 입출력을 담당합니다.
- **FMA 로드**: ZIP 기반 FMA v3와 기존 JSON/Base64 `.fma`를 자동 판별하여 내부 데이터 구조로 변환합니다.
- **이미지 추가**: 로컬 파일 선택·드래그, ZIP 내부 이미지 추출, 클립보드 버튼 및 `Ctrl+V` 붙여넣기로 프로젝트에 추가합니다.
- **지원 형식**: PNG, JPG, WebP, GIF, BMP, SVG, AVIF 이미지를 ZIP에서도 자동으로 찾아 추가합니다.
- **내보내기**: 현재 작업 상태를 `manifest.json + media/` 구조의 압축 `.fma`로 저장합니다. 기본 저장은 원본 바이너리와 내용 해시 기반 중복 제거를 사용합니다. 선택형 WebP 압축 저장은 PNG/JPEG/BMP를 품질 82로 변환한 결과가 더 작을 때만 적용합니다. 모든 이미지를 일반 `.zip`으로도 다운로드할 수 있습니다.

### 6. `js/image/crop.js` - 비파괴 이미지 Crop
선택한 이미지의 원본을 유지하면서 Crop 결과를 새 이미지로 생성합니다.
- **영역 선택 및 이동**: 캔버스 위에서 드래그하여 Crop 영역을 지정하고, 선택 영역 내부를 다시 드래그하여 위치를 이동할 수 있습니다.
- **비율 프리셋**: 자유, 1:1, 4:3, 3:4, 16:9, 9:16 비율을 지원합니다.
- **저장 방식 선택**: Crop 적용 시 원본 이미지 대체 또는 새 PNG 이미지 생성을 선택할 수 있습니다. 새 이미지는 원본 바로 뒤에 추가되며 `cropped` 그룹으로 분류됩니다.
- **자동 저장**: 생성 직후 갤러리, FMA 저장 데이터 및 IndexedDB 세션에 반영됩니다.

### 7. `js/image/imageUpscale.js` - 로컬 및 AI 이미지 업스케일
미리보기의 Crop 옆에서 이미지 해상도를 높이고 결과 저장 방식을 선택할 수 있습니다.
- **Canvas 업스케일**: 2×, 3×, 4× 고품질 보간과 0~1.5 샤픈 필터를 브라우저 안에서 처리합니다.
- **저장 방식 선택**: 처리 완료 후 원본 대체 또는 `upscaled` 그룹의 새 이미지 생성을 선택합니다.
- **AI Studio 연동**: Settings에서 API 키, AI 버튼 표시 여부, 2K/4K 해상도를 설정합니다.
- **API 키 발급 링크**: 설정의 `키 발급 ↗` 버튼에서 Google AI Studio 공식 API Keys 페이지를 새 탭으로 엽니다.
- **통합 설정 진입점**: 화면 우측 상단의 톱니바퀴 버튼에서 AI Studio 및 앱 부가 기능 설정을 엽니다.
- **Gemini 이미지 모델**: `gemini-3.1-flash-image`에 원본 보존형 업스케일 요청을 보내며 결과는 `ai-upscaled` 그룹으로 생성할 수 있습니다.
- **프롬프트 편집**: AI 업스케일 실행 전 프롬프트를 직접 수정하고 기본값으로 복원할 수 있으며 마지막 입력을 기억합니다.
- **출력 형식**: Gemini가 지원하는 JPEG로 결과를 요청해 지원되지 않는 PNG 응답 형식 오류를 방지합니다.
- **키 보관**: API 키는 브라우저 로컬 저장소에만 저장되고 AI 실행 요청의 `x-goog-api-key` 헤더에만 사용됩니다.

### 8. `js/image/backgroundRemove.js` - 로컬 및 AI 배경 제거
현재 이미지에서 배경을 투명하게 제거하고 PNG 결과를 프로젝트에 반영합니다.
- **브라우저 로컬 처리**: `@bunnio/rembg-web`과 `u2net_human_seg` 모델로 사람 중심 전경을 분리하며, 입력 이미지는 외부 처리 서버로 전송하지 않습니다.
- **로컬 모델 우선**: 앱 기준 `image_model/u2net_human_seg.onnx`를 먼저 확인합니다. 원본 링크에서 수동으로 받은 파일도 이 이름과 위치에 넣으면 사용됩니다.
- **다중 경로 탐색**: `image_model`, `Image_model`, `models`, 앱 루트 순서로 유효한 ONNX 응답과 파일 크기를 검사합니다.
- **직접 모델 선택**: 경로 접근이 차단된 실행 환경에서는 `ONNX 파일 선택`으로 모델을 직접 지정합니다. 선택한 모델은 별도 IndexedDB에 저장되어 다음 실행에도 재사용됩니다.
- **손상 캐시 복구**: 세션 초기화 실패 시 rembg 세션 및 해당 모델 캐시를 제거한 뒤 선택된 모델로 한 번 자동 재시도합니다.
- **모델 다운로드 안내**: 로컬 파일이 없으면 약 176MB 모델을 원본 서버에서 브라우저 캐시로 내려받으며, `모델 확인 · 미리 준비` 버튼으로 실행 전에 초기화할 수 있습니다.
- **모델 재사용**: 내려받은 모델은 IndexedDB에 캐시하고 세션을 재사용합니다.
- **AI Studio 연동**: Settings의 `AI Studio 배경 제거 버튼 표시`가 켜진 경우에만 AI 버튼을 표시합니다. 초기값은 꺼짐입니다.
- **AI 투명도 후처리**: Gemini JPEG 결과를 로컬 U²-Net으로 다시 분리해 최종 투명 PNG를 생성합니다.
- **프롬프트 편집**: AI가 유지할 피사체와 세부 요소를 실행 전에 직접 조절할 수 있습니다.
- **투명 PNG 저장**: 처리 완료 후 원본 대체 또는 `background-removed` / `ai-bg-removed` 그룹의 새 이미지 생성을 선택합니다.
- **FMA 보존**: 처리 방식, 원본 경로, 결과 크기를 FMA 저장 데이터에 함께 기록합니다.

### 9. `js/image/backgroundMaskEditor.js` - 배경 제거 정밀 보정
- **직접 붓**: 하드 원형, 소프트 원형, 사각 붓과 크기·강도를 설정해 알파를 지우거나 원본 픽셀을 복구합니다.
- **선택 편집**: 칠하기 또는 다각형으로 영역을 선택한 뒤 지우기·복구를 구분해 적용합니다.
- **정밀 탐색**: 전체화면, 화면 맞춤, `Alt + 마우스휠` 확대·축소, `Alt + 드래그` 이동을 지원합니다.

### 10. `js/image/imageMetadata.js` - 이미지 메타정보
- **이미지 하단 카드**: 용량, 종류, 해상도, 비율, 생성일, 그룹과 사용자 메타정보를 각 이미지 아래 표시합니다.
- **원본 메타정보**: `exifr`로 EXIF, XMP, IPTC 정보를 브라우저에서 읽어 전체 내용을 확인합니다.
- **편집 가능 정보**: 파일명·경로, 그룹, 생성일, 제목, 작성자, 저작권, 키워드, 설명 및 사용자 정의 필드를 추가·수정합니다.
- **프로젝트 저장**: 수정한 메타정보와 처리 이력을 IndexedDB와 FMA 내보내기에 보존합니다.

### 11. `js/core/interaction.js` - 사용자 상호작용 (Zoom & Pan)
마우스와 키보드를 통한 조작 로직입니다.
- **확대/축소 (Zoom)**: 상단 버튼 및 `Ctrl + 마우스 휠`을 통해 실시간 확대/축소가 가능합니다.
- **휠 탐색**: 가로 보기에서 중앙 미리보기 위로 일반 마우스휠을 움직이면 이전·다음 이미지로 이동합니다.
- **드래그 이동 (Pan)**: 확대된 상태에서 마우스를 클릭한 채 드래그하여 이미지의 특정 부분을 탐색합니다.
- **단축키**: 좌우 화살표 키를 이용한 빠른 이미지 탐색을 지원합니다.
- **패널 리사이즈**: 중앙 바를 조절하여 좌측 갤러리와 우측 미리보기 영역의 너비를 조정하고 이를 기억합니다.

### 12. `js/core/app.js` - 메인 제어 (Orchestrator)
모든 모듈을 초기화하고 이벤트 리스너를 결합하는 중심 파일입니다.
- **초기화 순서**: 그리드 설정 -> 데이터베이스 연결 -> 이벤트 바인딩 -> 모드 업데이트 순으로 실행됩니다.
- **이벤트 중앙 관리**: 상단 툴바의 모든 버튼 클릭 이벤트를 각 기능 파일의 함수와 연결합니다.

---

## 🚀 주요 성능 개선 포인트
1. **DOM Access 병목 해소**: 모든 주요 요소를 `dom` 객체에 사전 캐싱하여 접근 속도를 높였습니다.
2. **배치 렌더링**: 화면 업데이트 빈도를 최소화하기 위해 메모리 내에서 DOM 구조를 완성한 뒤 배포합니다.
3. **비동기 처리**: 대용량 이미지 로드 시 UI가 멈추지 않도록 비동기 전송 방식을 사용합니다.
