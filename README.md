# FMA Viewer Ultra

FMA Viewer Ultra는 여러 이미지를 한 프로젝트에서 모아 보고, 분류하고, 편집하고, AI로 수정한 뒤 다시 갤러리와 FMA 프로젝트로 저장하는 브라우저 기반 이미지 작업 도구입니다.

일반 이미지 추가부터 Crop, Resize/Upscale, 배경 제거, 정밀 보정, 필터·레이어·텍스트 편집, 메타정보 관리, Google AI Studio 기반 AI Jena 편집까지 하나의 화면에서 사용할 수 있습니다.

## 첫 실행과 개인정보

처음 실행하면 개인정보 처리방침과 최초 사용자 안내가 표시됩니다. 앱을 시작하려면 `@gmail.com` 주소를 입력하고 개인정보 처리방침에 동의해야 합니다.

`사용 신청하고 시작`을 누르면 Google Apps Script가 입력한 Gmail로 30분 동안 유효한 일회용 인증 링크를 발송합니다. 다음 정보는 인증을 완료한 뒤 등록 시스템에서 처리됩니다.

- 입력한 Gmail 주소
- 최초 사용 일자와 시각(시·분)
- 이메일 인증 일자와 시각
- 마지막 등록 확인 시각과 사용 상태

신청 알림 문구는 `[입력한 Gmail]이 FMA Viewer를 [연·월·일 시·분]에 사용 신청했습니다.` 형식입니다.

인증 전 신청은 Sheet에 기록되지 않으며 앱도 잠긴 상태를 유지합니다. 사용자가 메일의 인증 링크를 열면 Google Sheet의 `Users` 탭에 이메일당 한 행이 `Active`로 저장되고 `shoutjoy1@yonsei.ac.kr`로 인증 완료 알림 메일이 발송됩니다. 브라우저는 약 5초마다 인증 응답을 확인해 자동으로 앱을 시작합니다. 이후에는 관리자 설정 주기(기본 하루 1회)에 따라 Sheet의 이메일 존재 여부를 확인하고, 실행 중에는 기본 5분 간격으로 `Blocked` 변경을 감지합니다. 이메일이 삭제되면 다음 전체 동기화 때 다시 신청해야 합니다. 일시적인 서버 연결 실패만으로 기존 사용자를 차단하지는 않습니다. Gmail 비밀번호나 인증 토큰 원문은 앱이나 Sheet에 저장하지 않습니다.

`admin.html`에서 GAS 배포 URL, 하루 전체 점검 횟수(1~24회), `Blocked` 감시 간격(1~60분)을 현재 브라우저에 저장할 수 있습니다. 정적 웹앱과 GAS에는 서버 Push 연결이 없으므로 차단은 이 경량 확인 방식으로 반영됩니다. 설정은 동일 출처에만 적용되므로 Vercel, GitHub Pages, 로컬 파일 환경에서 각각 저장해야 합니다.

- `https://fmaviewer.vercel.app/admin.html`
- `https://shoutjoy.github.io/fmaviewer/admin.html`
- `file:///C:/CusorApps/fmaviewer/admin.html`

GAS 웹 앱은 인증 메일 발신 계정인 `shoutjoy1@gmail.com`에서 배포 사용자의 권한으로 실행하고, 로그인하지 않은 사용자도 접근할 수 있도록 공개 배포해야 합니다. 다른 계정으로 실행하면 health 검사와 메일 발송이 중지됩니다. JSON 대신 Google 로그인 화면이 반환되면 FMA Viewer는 배포 설정 오류를 표시합니다.

등록·알림 서버 코드와 배포 정보는 `Auth/gas/` 영역에서 관리하며 GitHub 배포 대상에서 제외합니다.

자세한 내용은 [FMA Viewer 개인정보 처리방침](Auth/PRIVACY_POLICY.md)을 확인하십시오.

## 2. 실행 방법

이 앱은 별도의 서버 프로그램 없이 브라우저에서 실행할 수 있습니다. 최신 Microsoft Edge 또는 Google Chrome 사용을 권장합니다.

### 간단 실행

`index.html`을 브라우저에서 엽니다.

일부 브라우저는 `file://` 환경에서 모델, iframe 또는 파일 접근을 제한할 수 있습니다. 그런 경우 프로젝트 폴더에서 로컬 HTTP 서버를 실행하십시오.

```powershell
cd C:\CusorApps\fmaviewer
python -m http.server 8000
```

그다음 브라우저에서 다음 주소를 엽니다.

```text
http://localhost:8000
```

### 권장 환경

- 최신 Microsoft Edge 또는 Google Chrome
- 이미지와 AI 모델을 저장할 충분한 브라우저 저장 공간
- AI 기능과 최초 모델 다운로드를 위한 인터넷 연결
- 대용량 프로젝트 사용 시 충분한 시스템 메모리

## 3. 빠른 시작

1. `File` 메뉴에서 `Open FMA`를 선택하거나 이미지 추가 영역을 엽니다.
2. 이미지 선택, ZIP 추가, 붙여넣기 또는 드래그 앤드 드롭으로 이미지를 넣습니다.
3. 왼쪽 갤러리에서 이미지를 선택합니다.
4. 이미지 상단의 `Edit`, `Crop`, `BG Remove`, `Upscale`, `AI Jena` 중 필요한 기능을 실행합니다.
5. 편집 결과는 `원본 대체` 또는 `새 이미지 생성`으로 저장합니다.
6. 작업 중에는 `SaveDB`로 브라우저에 상태를 저장합니다.
7. 다른 컴퓨터로 옮기거나 장기 보관할 때는 `Save FMA`로 FMA 파일을 내보냅니다.

## 4. 이미지 추가

### FMA 파일 열기

상단 `File → Open FMA`를 선택한 뒤 `.fma` 파일을 엽니다. FMA 파일 안의 이미지, 그룹, 즐겨찾기, 메타정보 및 지원되는 편집 정보가 복원됩니다.

### 일반 이미지 추가

다음 방법을 사용할 수 있습니다.

- `File → Add Image`
- 왼쪽 `이미지 선택`
- 이미지 파일을 추가 영역으로 드래그
- `Ctrl+V`로 클립보드 이미지 붙여넣기

### ZIP 이미지 추가

`ZIP 추가`를 누르거나 ZIP 파일을 추가 영역으로 드래그합니다. ZIP 안에서 지원되는 이미지를 찾아 갤러리에 추가합니다.

### 이미지 추가 영역 접기

이미지가 많아진 뒤에도 왼쪽 상단의 이미지 추가 패널을 접거나 다시 펼칠 수 있습니다.

## 6. 저장과 불러오기

FMA Viewer에는 목적이 다른 세 가지 저장 방식이 있습니다.

| 방식 | 용도 | 저장 위치 | 특징 |
|---|---|---|---|
| Save FMA | 프로젝트 내보내기·장기 보관·이동 | 사용자가 선택한 파일 위치 | 이미지와 프로젝트 정보를 하나의 `.fma` 파일로 저장 |
| SaveDB | 작업 중간 상태와 여러 버전 보관 | 현재 브라우저의 IndexedDB | 빠른 재사용, 저장 히스토리 관리 |
| Download ZIP | 결과 이미지만 일괄 내보내기 | 사용자가 선택한 다운로드 위치 | 편집 가능한 프로젝트 정보 없이 이미지 파일만 압축 |

### Save FMA

`File → Save FMA` 또는 왼쪽의 정사각형 `Save FMA` 버튼을 사용합니다.

FMA 파일에는 다음 정보가 포함될 수 있습니다.

- 이미지 데이터
- 이미지 경로와 그룹
- 즐겨찾기
- 생성·수정 시각
- 파일 종류와 크기
- 사용자 메타정보
- Crop, Upscale, 배경 제거 및 이미지 편집 관련 정보

이미지는 Base64 데이터로 포함되므로 이미지 수가 많으면 FMA 파일 크기도 커집니다.

### Open FMA

`File → Open FMA`에서 저장된 `.fma` 파일을 선택합니다. 대용량 FMA 파일은 분석과 화면 구성에 시간이 걸릴 수 있습니다.

### SaveDB

`SaveDB → 현재 상태 SaveDB`를 누르면 현재 이미지 목록과 화면 상태를 브라우저 IndexedDB에 저장합니다.

이미지 본문은 한 개의 거대한 Data URL 레코드가 아니라 개별 `Blob`으로 저장되고,
저장본은 Blob ID를 참조합니다. 같은 작업을 다시 저장할 때 이미지별 데이터를 관리할 수
있어 대용량 저장본의 읽기·쓰기 중 멈춤을 줄입니다. 기존 형식의 저장본도 계속 불러올 수
있습니다.

저장되는 주요 상태:

- 전체 이미지
- 현재 선택 이미지
- 정렬 방식
- Grid 열 수
- Single/Two 보기
- 이동 단위
- 보기 방향과 확대 상태

### DB 히스토리

`SaveDB → DB 히스토리`에서 저장본 목록을 확인할 수 있습니다.

- `FMA Viewer로 불러오기`: 선택한 저장본 복원
- `삭제`: 선택 저장본 삭제
- `전체 삭제`: 모든 SaveDB 히스토리 삭제
- 대용량 저장본은 단계별 진행률과 퍼센트 표시

대용량 저장본은 팝업에서 이미지 전체를 복사하지 않고 메인 FMA Viewer가 IndexedDB에서 직접 읽습니다. 복원이 끝날 때까지 FMA Viewer와 DB 히스토리 창을 닫지 마십시오.

### IndexedDB 주의사항

- SaveDB는 현재 브라우저와 현재 브라우저 프로필에만 저장됩니다.
- 시크릿/InPrivate 창의 데이터는 보존되지 않을 수 있습니다.
- 브라우저 사이트 데이터나 저장 공간을 삭제하면 SaveDB와 AI Jena 히스토리도 삭제됩니다.
- 다른 컴퓨터나 다른 브라우저로 옮길 때는 반드시 FMA 파일도 별도로 저장하십시오.
- 브라우저 저장 공간이 부족하면 대용량 저장이 실패할 수 있습니다.

## 7. Crop

이미지 위의 `Crop` 버튼을 누릅니다.

1. 자유, 1:1, 3:4, 4:3, 9:16, 16:9 중 비율을 선택합니다.
2. 이미지 위에서 영역을 만들고 드래그하여 이동합니다.
3. 필요하면 가로·세로 픽셀 값을 입력하고 `수치 적용`을 누릅니다.
4. `Crop 적용`을 누르면 결과 미리보기가 표시됩니다.
5. `원본 대체` 또는 `새 이미지로 갤러리에 추가`를 선택합니다.

## 8. Upscale과 Resize

이미지 위의 `Upscale` 버튼을 누릅니다.

### Canvas Upscale

브라우저 Canvas에서 이미지를 확대하고 이미지 보간과 Sharpen을 적용합니다. 이미지는 외부 서버로 전송되지 않습니다.

### Resize

가로·세로 픽셀을 직접 입력하여 원하는 해상도로 변경합니다. 비율 유지 옵션을 사용하면 한쪽 수치 변경 시 다른 수치가 함께 계산됩니다.

### AI Upscale

설정에서 Google AI Studio API 키와 AI Upscale 버튼을 활성화하면 사용할 수 있습니다.

1. AI Upscale 모드를 선택합니다.
2. 2K 또는 4K 등 출력 해상도를 선택합니다.
3. 필요한 보정 내용을 프롬프트에 입력합니다.
4. 실행 후 결과를 원본 대체 또는 새 이미지로 저장합니다.

AI 작업 중에는 정지 버튼으로 요청을 중단할 수 있습니다.

## 9. 배경 제거

### 브라우저 로컬 배경 제거

`BG Remove`를 열고 브라우저 로컬 배경 제거를 선택합니다.

- 기본값인 `WebGL 엔진 우선`은 BG Remover 앱과 같은 MediaPipe 방식으로 처리하므로 176MB ONNX 모델이 필요하지 않습니다.
- WebGL 엔진의 경량 런타임은 최초 실행 시 CDN에서 불러온 뒤 브라우저 캐시를 이용합니다.
- `커스텀 단색 배경`을 체크하면 투명 영역에 원하는 색을 합성하여 저장할 수 있습니다.
- `ONNX 모델 적용`을 선택한 경우에만 U²-Net 모델 자동 다운로드 및 수동 선택 설정이 나타납니다.
- ONNX 자동 연결이 실패하면 `ONNX 수동 선택`으로 내려받은 모델 파일을 직접 선택합니다.
- `image_model` 폴더의 ONNX 모델 파일을 로컬 HTTP 환경에서 사용할 수도 있습니다.
- 처리할 이미지는 외부 AI 서버로 전송되지 않습니다.

### AI Studio 배경 제거

설정에서 AI 배경 제거 버튼을 활성화하고 API 키를 적용한 경우 사용할 수 있습니다. 프롬프트를 수정하여 제거 방식과 보존할 요소를 지정할 수 있습니다.

### 배경 제거 정밀 보정

자동 배경 제거가 완벽하지 않을 때 정밀 보정을 사용합니다.

- 직접 붓
- 칠해서 선택
- 다각형 선택
- 지우기와 복구
- 붓 크기, 강도와 종류
- 다각형 선택 저장·불러오기
- 텍스트 레이어
- 전체 화면과 화면 맞춤
- 확대 후 이동
- `Ctrl+Z` Undo

완료 후 `갤러리에 추가`를 누르면 보정 결과가 FMA Viewer 갤러리에 추가됩니다.

## 13. AI Jena 사용법

AI Jena는 Google AI Studio의 이미지 생성·편집 모델을 이용하는 대화형 이미지 편집 기능입니다.

### 시작

1. 설정에서 AI Studio API 키를 입력하고 키 사용을 활성화합니다.
2. 갤러리에서 편집할 이미지를 선택합니다.
3. 이미지 메뉴의 `AI Jena`를 누릅니다.
4. API 키가 없거나 중지되어 있으면 먼저 설정하라는 안내가 표시됩니다.

### 작업 방식

#### 이미지 수정

현재 이미지의 전체적인 색, 배경, 의상, 표정 또는 세부 요소를 프롬프트로 수정합니다.

예:

```text
인물은 유지하고 배경을 밤의 서울 거리로 변경해줘.
```

#### 선택영역 수정

1. `선택영역 수정`을 선택합니다.
2. `붓 선택` 또는 `다각형 선택`을 선택합니다.
3. 붓 크기와 선택 농도를 조절합니다.
4. 이미지에서 변경할 영역을 선택합니다.
5. 선택한 부분을 어떻게 바꿀지 프롬프트에 입력합니다.

다각형은 시작점과 각 점이 표시됩니다. 최소 3개 점을 만든 뒤 시작점을 다시 누르거나 `다각형 선택 완료`를 누릅니다. 완성된 다각형 내부를 드래그하면 선택 영역을 이동할 수 있습니다.

선택 영역이 있으면 AI는 주변 이미지와 배경을 고려하여 해당 영역을 자연스럽게 수정하도록 요청받습니다.

#### 전체 포즈 변경

인물의 전체 자세나 구도를 변경할 때 사용합니다.

예:

```text
같은 인물이 양손을 허리에 둔 자연스러운 전신 포즈로 바꿔줘.
```

포즈 라이브러리는 `전체 포즈 변경`과 `Try-on`에서 함께 사용할 수 있습니다. `사용자 포즈 추가·저장`을 펼치면 새 주제와 자세를 추가할 수 있으며, 추가 즉시 IndexedDB에 저장됩니다. 사용자 포즈는 JSON으로 내보내거나 다시 불러올 수 있고 기본 100가지 포즈는 삭제되지 않습니다.

### 참고 이미지 가져오기

얼굴, 옷, 배경, 자세의 각 참고 이미지 칸에서 다음 두 방식을 사용할 수 있습니다.

- `PC`: 컴퓨터의 이미지 파일 선택
- `FMA`: 현재 FMA Viewer 갤러리에서 이미지 선택

FMA 선택창은 현재 갤러리 정렬 순서를 따릅니다. 선택된 이미지는 데이터 URL 참고 자료로 변환되어 AI 요청과 참고 세팅 저장·내보내기에 함께 사용됩니다.

#### 새 이미지 생성

원본 수정이 아닌 새로운 이미지 생성에 사용합니다. 인물, 배경, 구도, 조명, 분위기와 스타일을 자세히 작성할수록 결과를 조절하기 쉽습니다.

#### Veo 영상 생성

AI Jena에서 Google Veo를 이용해 프롬프트 기반 영상을 생성할 수 있습니다.

1. 작업 방식에서 `영상 생성`을 누르거나 채팅 하단의 `Veo 영상` 버튼을 누릅니다.
2. Veo 3.1 모델과 `16:9` 또는 `9:16` 화면비를 선택합니다.
3. 현재 이미지를 첫 장면으로 움직이게 하려면 `현재 이미지를 첫 프레임으로 사용`을 켭니다.
4. 움직임, 카메라 이동, 장면, 조명, 분위기와 소리를 프롬프트에 입력합니다.
5. `영상 생성` 또는 `Ctrl+Enter`를 누릅니다.
6. 완료된 영상은 중앙에서 재생하고 `영상 다운로드`로 MP4 파일을 저장합니다.

Veo 작업은 비동기로 처리되어 수 분이 걸릴 수 있습니다. `정지`는 브라우저의 요청 및 상태 확인을 멈추지만, 이미 Google에 제출된 작업 자체는 서버에서 계속 처리될 수 있습니다. Veo 사용 권한과 과금은 연결된 Google AI Studio API 키의 프로젝트 정책을 따릅니다.

### 실행과 중지

- `AI 실행`: 프롬프트 실행
- `Ctrl+Enter`: 프롬프트 입력창에서 바로 실행
- `정지`: 진행 중인 AI 요청 중단
- 진행 메시지와 프로그레스 바에서 현재 상태 확인

### 확대와 이동

- `Alt + 마우스 휠`: 25%~800% 확대·축소
- `Alt + 드래그`: 확대된 이미지 이동
- 좌측 상단 배율 버튼: 100%와 중앙 위치로 초기화

### AI Jena 히스토리

각 AI 결과는 오른쪽의 작은 히스토리 이미지로 저장됩니다.

- 미리보기 선택: 해당 결과를 크게 표시
- 이전 결과에서 프롬프트 편집 계속하기
- 각 항목의 `×`: 선택 히스토리 삭제
- 하단 `히스토리 전체 지우기`: 해당 이미지의 전체 AI 작업 기록 삭제

히스토리는 IndexedDB에 저장되어 창이나 브라우저를 다시 열어도 같은 원본 이미지에서 복원됩니다. 브라우저 사이트 데이터를 삭제하면 함께 삭제됩니다.

### 갤러리로 보내기

AI 결과 완성 후 `갤러리로 보내기`를 누릅니다.

- `돌아가기`: AI Jena로 돌아감
- `원본 대체`: 현재 원본 이미지를 AI 결과로 교체
- `새 이미지 생성`: 원본을 유지하고 AI 결과를 새 갤러리 이미지로 추가

## 17. 문제 해결

### SaveDB 복원이 오래 걸립니다

- 대용량 저장본은 IndexedDB에서 직접 읽고 이미지를 순차 복원합니다.
- 프로그레스 바가 완료될 때까지 FMA Viewer와 DB 히스토리 창을 열어 두십시오.
- 브라우저 메모리가 부족하면 다른 탭이나 대용량 앱을 닫은 뒤 다시 시도하십시오.
- 계속 실패하면 FMA 파일로 저장한 백업을 사용하십시오.

### 이미지가 메인 화면 밖으로 이동했습니다

`Fullscreen` 옆의 `⌖ 원위치`를 누릅니다. 배율을 포함해 모두 초기화하려면 `Reset Zoom`을 누릅니다.

### AI Jena 버튼을 눌러도 실행되지 않습니다

- 톱니바퀴 설정에서 API 키가 입력되었는지 확인합니다.
- `키 사용 중지` 상태인지 확인합니다.
- 인터넷 연결과 Google API 사용 가능 여부를 확인합니다.

### 로컬 배경 제거 모델을 읽지 못합니다

1. 기본 `WebGL 엔진 우선`을 선택하면 ONNX 모델 없이 배경을 제거할 수 있습니다.
2. WebGL 실행에 실패하면 인터넷 연결과 브라우저의 WebGL 사용 설정을 확인합니다.
3. ONNX를 사용하려면 `ONNX 모델 적용`을 누른 뒤 `모델 자동 다운로드 · 연결`을 다시 실행합니다.
4. 자동 연결이 실패하면 원본 ONNX 모델을 내려받아 `ONNX 수동 선택`으로 지정합니다.
5. 로컬 서버 사용 시 `image_model` 경로와 HTTP 접근 여부를 확인합니다.

### 외부 앱 결과를 가져올 수 없습니다

- 앱이 완전히 로딩되었는지 확인합니다.
- 진행 상태가 `연결 완료`인지 확인합니다.
- 내부 앱을 새로고침한 뒤 다시 생성하거나 가져오기를 실행합니다.
- 브라우저의 iframe, 팝업 및 클립보드 권한을 확인합니다.

## 19. 사용 시 참고

- 생성형 AI 결과는 원본과 다를 수 있으므로 중요한 작업은 `새 이미지 생성`으로 먼저 보관하는 것을 권장합니다.
- 편집 전 원본을 FMA 또는 SaveDB로 백업하십시오.
- FMA, SaveDB, AI 히스토리에 포함된 이미지가 많으면 저장 공간과 메모리 사용량이 크게 증가합니다.
- 브라우저 저장은 영구 백업을 대신하지 않습니다. 중요한 프로젝트는 FMA 파일과 결과 ZIP을 별도로 보관하십시오.
